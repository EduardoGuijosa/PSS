Digitaliza y organiza la liberación del Servicio Social

Nuestro sistema centraliza proyectos, actividades, horas y seguimiento del servicio social, permitiendo a estudiantes, tutores, responsables y subdirección llevar un mejor control del proceso.

ACCEDER Conocer más

¿Qué encontrarás en esta plataforma?

  • Catálogo digital de proyectos y actividades
  • Control de horas acumuladas y pendientes
  • Seguimiento académico por alumno y grupo
  • Administración de usuarios y grupos
  • Mejor organización del proceso de liberación

¿Qué es y qué hace el sistema?

Es una aplicación web para gestionar el servicio social de la UTM, donde los estudiantes pueden consultar y registrarse en actividades, mientras que tutores, responsables y subdirección supervisan el avance y el cumplimiento de las 480 horas requeridas.

Problemática que atiende

Actualmente el proceso del servicio social puede resultar poco organizado por la falta de un catálogo centralizado, dificultades para conocer proyectos disponibles, complicaciones en el seguimiento y procesos manuales que generan retrasos y confusión.

Solución que ofrece

La plataforma centraliza la información, facilita la selección de actividades, mejora la supervisión de grupos y permite llevar un control más claro del avance del servicio social para todos los actores involucrados.

Funciones principales del sistema

El sistema fue pensado para hacer más claro, ordenado y eficiente el proceso de liberación del servicio social.

Catálogo digital

  • Consulta de proyectos disponibles
  • Visualización de actividades y horas
  • Registro de alumnos en actividades

Seguimiento y control

  • Control de horas acumuladas
  • Seguimiento de tareas por alumno
  • Visualización de avance y estatus

Administración

  • Gestión de alumnos, tutores y responsables
  • Administración de grupos
  • Supervisión del proceso por subdirección

Roles de usuarios dentro del sistema

Cada usuario cuenta con funciones específicas para facilitar la organización y control del servicio social.

🎓

Alumno

Consulta proyectos, se registra en actividades y visualiza su progreso.

👨‍🏫

Tutor

Administra grupos y da seguimiento al avance de sus alumnos.

🧑‍💼

Responsable

Gestiona proyectos, tareas y evalúa el cumplimiento de actividades.

🏢

Subdirección

Supervisa y controla el proceso general del servicio social.

Tecnología de desarrollo

El sistema se construyó como una aplicación web usando herramientas de desarrollo y almacenamiento de información orientadas a la gestión.

Tecnologías utilizadas

  • HTML, CSS y JavaScript
  • Node.js y Express
  • MySQL / MariaDB
  • Bootstrap

Recursos tecnológicos

  • Computadoras para diseño y desarrollo
  • Acceso a internet para investigación y pruebas
  • Base de datos para usuarios, actividades y horas
  • Servidor web y navegadores para pruebas
